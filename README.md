# 📖 Overview

MingleMakers is a **digital ecosystem** designed to empower **artisans and suppliers** by solving one of the biggest challenges in the craft industry—**raw material procurement**.

Unlike traditional marketplaces that focus only on selling finished products, MingleMakers addresses the **supply-side problem**, enabling artisans to access quality raw materials at affordable prices while fostering collaboration and sustainability.

The platform follows a **Dual-Track Ecosystem**:

### 🎨 Artisan Track
- Connect with trusted suppliers
- Discover quality raw materials
- Exchange materials through barter & swap
- Join artisan communities
- Access sustainable and eco-friendly resources

### 🏭 Supplier Track
- Reach artisans directly
- Showcase products and stock availability
- Expand business visibility
- Build a sustainable supply chain

# 🛠️ Installation

Clone the repository:

```bash
git clone https://github.com/Raksha-3063/MingleMakers.git
```

Navigate to the project folder:

```bash
cd MingleMakers
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
